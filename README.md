# Controle Parcelas

MVP para controle de valores a receber e pagamentos parcelados.

## Recursos atuais
- Dashboard responsivo
- Cadastro de pessoa/dívida
- Total recebido e saldo pendente
- Progresso por parcelamento
- Registro rápido da próxima parcela
- Busca de pessoas

## Rodar
```bash
npm install
npm run dev
```

## Próxima etapa
Persistência em banco, autenticação, acesso individual do pagador, histórico auditável e notificações.
